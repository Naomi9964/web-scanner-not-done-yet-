WHAT IT DOES

Five focused views of one public page.

The scanner reads one public page and turns visible configuration and markup signals into separate category scores. It is designed for classroom demonstrations, development reviews, and quick website audits.

01 / SECURITY

Browser defenses

Reviews security headers, cookie attributes, CORS, mixed content, and unnecessary technology disclosure.

02 / TLS & DOMAIN

Connection health

Validates HTTPS, the certificate chain and lifetime, public DNS resolution, and redirect behavior.

03 / PAGE QUALITY

Page metadata

Checks the title, description, document language, mobile viewport, and canonical URL.

04 / ACCESSIBILITY

Basic accessibility

Checks language, image alternatives, form control names, and heading structure in the downloaded HTML.

05 / PERFORMANCE

Lightweight performance

Scores response time, HTML response size, and redirect count without running a full browser benchmark.

HOW IT WORKS

From URL to priorities in three steps.

No account, API key, or external scanning service is required. The project runs locally with Python.

1. Enter a public URL

The input is normalized and checked before any network connection begins.

2. Fetch within strict boundaries

Only HTTP 80 and HTTPS 443 are allowed. DNS answers and every redirect are checked against private and special-use networks.

3. Review the report

Each signal is marked as passed, informational, needing attention, or a clear risk, with a suggested next action.
